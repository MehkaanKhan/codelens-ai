Schema & Architecture
Database Type

CodeLens AI uses ChromaDB — an open-source, embedded NoSQL vector database. Unlike relational databases, it stores documents paired with high-dimensional embedding vectors. Queries find the semantically closest documents by cosine distance across an HNSW index — no exact key match required.

Why NoSQL over SQL?

Code search is a semantic problem, not a keyword problem. WHERE code LIKE '%save%' can't find serialize() or write_to_file(). By storing code as 768-dim embeddings, ChromaDB matches intent — a query about "persistence" retrieves the right functions even if the word never appears in them.
